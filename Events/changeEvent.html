Change Event:-

The change Event occurs when the value of an element has been changed (only works on input tag, textarea tag and select tag elements.)

Jab bhi inn tino element me koi bhi changes aaiga to change event use track karta hai.

Ye cahnges track karne ke liye change event initial statement and final statement dono ko compare karta hai.


Example:- kabhi kabhi hum kucch websites prr dekhte hai ki search button nhi raheta hai sirf hum jo enter karte jaate hai automatic search hota jaata hai jaise hi kuch phir se changes kiye phir se wo track hota hai and then phir se search ho jaata hai.
